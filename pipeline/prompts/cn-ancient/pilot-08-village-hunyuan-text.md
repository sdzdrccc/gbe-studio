# 试产 08 · 槐阴村剩余资产：混元文生 3D 提示词

> 用途：**直接喂混元 3D 的文生 3D**（不经过三视图、不经过图像模型）。
> 与 pilot-04~07 的区别：那些是「先用图像模型出三视图，再图生 3D」；本文件是**一句话直接出模**，适合形状简单、材质统一的村中物件。
> 已出 3D、无需再生成的：民居 A / B / C / D、半塌民居、村口老槐（`old-locust-a-normalized.glb`）。
> **已有三视图、建议走图生 3D 的**：学堂半废厢房（`pilot-05` 的 `village-school-b` 三张）、废洞洞口（`pilot-04` 的 `cave-mouth` 三张）、墙基废墟（`pilot-06` / `PILOT-2026-10-25` 的 `village-ruin-b` 四张）——这三件不要浪费文生额度，直接喂图更准。

---

## 0. 通用写法

**正向前缀（每件都拼在最前面）**

```text
写实风格，中国古代北方贫困村落的{物件}，土坯墙、灰瓦、旧木、冷灰石、陶，风化做旧，材质低饱和，结构准确，单件完整，无底座，无场景，无人物，PBR 材质。
```

**通用负向（填在负向框，或拼在正向末尾）**

```text
底座，展台，地面，场景，人物，动物，文字，字母，匾额题字，对联，卡通，平涂，低模色块，现代物品，塑料，金属桶，红墙金漆，彩画，汉白玉，多件主体。
```

> 混元对「无底座」很敏感：每件都写。出模常带 0.05–0.2 m 的薄底盘，后处理时切掉即可。
> 尺寸不用写进提示词——混元归一化后只有约 1 m，尺寸在 Blender 里按 §3 的信封统一缩放。

## 4. 出模后统一处理

1. 缩放到 §3 / 各件的设计尺寸（`minju-earth-*` 的口径见 `MODEL-INVENTORY.md` 第十节）。
2. 轴心归到底面中心；`+Y up` / `-Z forward`。
3. 减面：建筑 15k–20k、道具 5k–15k、石组 10k–20k。
4. 贴图压到 1024、非透明转 JPEG。
5. 命名与落点：`F:\zxc\db\models\huaiyin\<asset>.glb`（ASCII 名），预览与处理记录放同目录；报告更新到 `MODEL-INVENTORY.md` 第十节。

## 5. 额度建议

- 第 1 天：A 组 6 件 → 6 次；加学堂 / 废洞 / 墙基废墟三组图生 3D → 3 次；共 9 次，留 11 次重试。
- 第 2 天：B 组 4 件 → 4 次；留 16 次给不合格件重滚。
- 不做：篱笆 / 晒架（GBE 已有灰模）、地面 / 土路 / 薄田（UE Landscape）、人物 / 牲畜（角色管线）、带字匾额（字必乱）。
