## 2. 单视图骨架（十件都拼它，适配自 pilot-06 §2）

```text
【画面类型】3D 建模用的单件道具单视角设定稿（orthographic ortho view）。
一次只画这件（这组）道具的一个正交视角（正视 / 侧视 / 俯视），不画三格、不画多视角拼图。

【呈现】物件孤悬于画面中央，不接触地面、不带底座、不带场景、不带地面片；
物件完整入画，四周留约 8% 空白，不裁切顶部与底部。

【镜头】严格正交投影（orthographic），相机光轴水平且与所看的面垂直；无透视、无俯仰、无倾斜、无广角畸变、无灭点。

【背景与光照】纯中性灰 #808080 平光背景，无渐变、无纹理、无地平线、无地面、无投影、无环境反射；
受光均匀，暗部保留结构层次；材质低饱和。

【风格】写实国风 · 北方穷村 · 次世代游戏资产 · PBR 材质 · 适度做旧：风化、雨痕、边角磨损、灰缝、土坯剥落；
不是卡通、不是平涂、不是低模色块；夯土、小青瓦、旧木、灰石、陶五类材质可辨。
★★ **同组三张必须是同一质感**（同一次写实 PBR 渲染）——实测俯视与侧视极易漂成**卡通描边 / 平涂插画 / 线稿**，与正视图对不上；
一旦出现描边黑线、平色块、插画感即判废重出（pilot-07 实测翻车 4 次：猪圈俯视、农具侧/俯、溪口俯视）。

【禁止】画面内不得出现文字、字母、数字、尺寸标注（★ 包括 `1m`、`04m` 这类**尺寸数字** —— 实测俯视会自动标注尺寸，出图即查）、箭头、辅助线、表格框、**边框线/图框**、logo、水印；
单件类不得出现第二件独立主体（组类只画本组各件）；不得出现局部特写小图、场景、人物、动物、云雾、光效、粒子；不得出现透视灭点。
```

> ★ **背景与 pilot-05/06 统一为 #808080**（原稿写 #d9d9d9；同批同底灰，三批图能直接并排比对）。

### 2.1 三张公共视角段（每张拼在骨架后）

**正视图（第一张）**

```text
【视角】正视图：正对物件正面，光轴水平且与正面垂直，正交投影；只见正面本身，两侧不露侧面。
所有竖线完全竖直，所有水平线完全水平；没有灭点、没有近大远小、没有广角畸变。
【看点】按物件段的描述逐项核对：整体轮廓、开敞面 / 门口 / 开口的位置、材质分界、做旧痕迹。
```

**侧视图（第二张）**

```text
【视角】侧视图：正对物件的一侧看过去。
这张要的是立面图（elevation drawing），不是照片，也不是四分之三视角：
被看的这一侧与画面平行；物件的另一侧完全藏在后面，画面里一点都不许出现；
相机光轴水平且与侧面垂直，严格正交投影；所有竖线完全竖直、所有水平线完全水平；没有灭点、没有近大远小。
★ 实测最易翻车点（柴房 / 猪圈都翻过）：**开敞面、门洞、第二面墙只要露一个角，就是四分之三视角** ——
看点里必须点名"画面里只许存在被看的这一个面，不许看到开敞口 / 柴堆 / 第二个立面"。
★ 若物件有"轴指向观者"的结构（辘轳轴、碾磙轴）：侧视里**只见轴端头**，整根轴不许横贯画面（那属于正视图）。
【看点】按物件段的描述核对侧面轮廓与进深关系；画面里不许出现转角透视，不许出现物件另一侧的面。
```

**俯视图（第三张）**

```text
【俯视的图面性质】这是从正上方垂直往下看的正投影俯视图（顶面平面图），不是航拍照片、不是鸟瞰、不是透视、不是四分之三视角。
相机光轴垂直向下，严格正交投影；所有水平线完全水平，所有竖线完全竖直；没有灭点、没有近大远小、没有地平线。
镜头正对着物件的**顶面**：画面里只看得到顶面本身的纹理与边缘，
**看不到任何立面** —— 看不到侧面、看不到门窗洞口、看不到地面、看不到底座、看不到物体的厚度。
物件孤悬在画面中央，物件之外全是干净的空白背景（中性灰 #808080），四周留约 10% 空白。
画面里不许出现本组之外的第二组物件、不许出现剖切面、不许出现尺寸标注与文字。
【俯视的比例判读】俯视图里物件的长宽比必须与正视图里的宽、侧视图里的深一致；目标比 = §0 尺寸信封的「总宽 : 总深」。
同一张图里横向的长度与纵向的长度之比要读得出来（不要画成过扁的长条，也不要画成窄高条）。
【组类的摆放】组类物件在三张里必须保持同一套摆放：俯视图里各件在画面里的位置按物件段的【方位】句摆，
不许重新排列（多体量平面图必须写死方位，否则模型会把各件画到别的位置 —— pilot-06 实测）。
```

> ★ **为什么要有俯视加料段**（来自 pilot-06 实测）：只写「从正上方往下看」四张全画错；
> 加料段把三件事说死 —— **① 只看得到顶面；② 物体之外全是空白；③ 比例要读得出来**，三件建筑俯视一次就成了。
> ★ **组类必须写死方位**：多体量平面图只说「成组摆放」不够，模型会重排（pilot-06 house-d 实测）。
> ★ 极端长宽比（> 10 : 1，本批无）才需要 pilot-06 §3.4 的英文剪纸贴片写法。

## 3. 十件的完整提示词（物件段，三张共用，拼在骨架与视角段之后）

### 3.1 院门 `village-gate-a`

```text
【物件定义】中国北方穷村的一处土坯院门：一段矮土墙中间开一个门洞，装双扇旧木板门，门上有小灰瓦门楼；只画院门这一小段，不画整圈院墙与院内。
【形制】土坯墙段总宽 3.2 m、高 1.8 m、厚 0.5 m，墙顶有少量草秸压顶；中间门洞宽 1.2 m、高 1.9 m；
双扇旧木门向内微开（约 15°），门板有竖向木纹与两道横压条；门洞上方小门楼：两坡小青瓦、出檐约 0.25 m、脊高约 2.6 m；
门洞两侧各一块门枕石，冷灰；门前没有台阶与铺装。
【材质】土坯墙暖灰褐、墙皮剥落；小青瓦深灰；门木深褐近黑；门枕石冷灰；墙顶草秸干黄。
【负向】无整圈院墙、无门神画、无红对联、无石狮、无斗拱、无人物、无文字。
```

出图后看：门楼是否只压在门洞上方、两坡与墙顶的关系是否合理；门洞不能被画成牌坊式高门。

### 3.2 土地庙 `village-shrine-a`

```text
【物件定义】中国北方村口的一座小土地庙：砖石小龛，单间，灰瓦小屋顶，龛内一尊粗凿石像，龛前一只石香炉；只画这一座小庙。
【形制】台基 1.4 × 1.0 m、高 0.2 m，冷灰石；庙身宽 1.0 m、深 0.7 m、高 1.1 m，青砖砌筑、灰缝清楚；
正面开一个拱形龛门，宽 0.5 m、高 0.7 m；龛内石像为粗略人形坐像，高约 0.45 m，不刻画五官；
屋顶为小青瓦两坡，出檐 0.2 m，脊高约 1.6 m，正脊两端微翘但不做鸱吻；龛前石香炉 0.3 m 见方。
【材质】青砖冷灰偏青；小青瓦深灰；石像与香炉冷灰；台基有雨痕与苔痕。
【负向】无红墙、无金漆、无匾额、无文字、无人物、无供品、无香火烟雾；不要画成庙宇大殿。
```

出图后看：龛门内必须能读出坐像轮廓；屋顶是两坡小瓦顶，不能画成单坡或平顶。

### 3.3 井台 `village-well-a`

```text
【物件定义】中国北方村中的一口石砌水井：圆形石井圈、方形石台面、木辘轳架与一只旧木桶；只画井台本体，不画周围地面。
【形制】方形石台面 1.6 × 1.6 m、厚 0.15 m，冷灰石错缝；中央圆形井圈外径 0.9 m、内径 0.6 m、高 0.35 m；
井口内近黑但可见少量水面反光；井台后方立木辘轳架：两根立柱高 1.2 m、一根横轴、一个手摇柄，木色深褐；
横轴上绕麻绳，绳端挂一只旧木桶，桶高 0.3 m，桶口朝上。
【方位】俯视图里：方形石台面居中，圆形井圈在台面正中，辘轳架两根立柱在台面**靠后**的边上、左右各一根，木桶挂在右立柱内侧。
【材质】石台面与井圈冷灰、边角磨圆；木架深褐旧木；麻绳干黄；木桶深褐、有铁箍。
【负向】无亭子、无石栏板、无人物、无文字、无水面满溢；不要画成景区许愿井。
```

出图后看：井口必须是圆的、井圈完整；辘轳架不能画成牌坊或门框；正视图里井圈在前、架柱在后，两者的前后关系一眼可读。

### 3.4 柴房 `village-woodshed-a`

```text
【物件定义】中国北方穷村的一间半开敞柴房：三面土坯矮墙、正面开敞，单坡草顶，里面堆满劈柴；只画柴房本体。
【形制】平面 3.5 × 2.6 m，后墙与两侧墙高 2.2 m、厚 0.4 m，正面无墙；
单坡屋顶从后墙 2.6 m 斜向前檐 2.0 m，草秸顶、厚约 0.15 m，檐口参差；
房内堆劈柴：长短不一的原木与劈柴横竖交错，堆高约 1.5 m，部分柴头探出开敞面；地面没有铺装。
【材质】土坯墙暖灰褐、剥落；草顶干黄灰；劈柴断面浅木色、树皮深褐；无瓦。
【负向】无门扇、无窗、无瓦顶、无人物、无文字、无农具；不要画成完整民居。
```

出图后看：正面必须开敞、能看见柴堆；屋顶是单坡草顶，不能画成两坡瓦顶。

### 3.5 石碾 `village-millstone-a`

```text
【物件定义】中国北方村中的一盘石碾：圆形石碾盘、立式石碾磙、木架与木推杆；只画石碾本体。
【形制】圆形碾盘直径 2.2 m、厚 0.25 m，冷灰石，盘面有放射状凿纹与一圈碾道；中央立木轴，高 0.8 m；
碾磙为圆柱形石滚，直径 0.6 m、宽 0.5 m，横卧在碾盘上，中心穿木轴与中央木轴相连；
木推杆从碾磙轴向外伸出，长约 1.2 m，深褐旧木；碾盘外缘有少量碎石与谷壳。
【方位】俯视图里：碾盘是正圆居中，碾磙横卧在碾盘**右半侧**、与推杆成一条线，推杆斜向右下伸出盘外；中央木轴在圆心。
【材质】碾盘与碾磙冷灰石、表面磨光；木轴与推杆深褐；碎石冷灰；谷壳干黄。
【负向】无牲畜、无人物、无棚子、无文字、无电动设备；不要画成磨坊或石磨盘（立式磨）。
```

出图后看：必须是「横卧碾磙 + 圆形碾盘 + 中央立轴」的石碾，不是两片石磨。

### 3.6 猪圈 / 鸡舍 `village-pen-a`

```text
【物件定义】中国北方穷村的一处土坯矮墙围成的小猪圈，一侧带一个草棚，角落有一个鸡舍小门；只画这一处圈舍。
【形制】矩形围合 3.0 × 2.2 m，土坯矮墙高 0.8 m、厚 0.3 m，墙顶不平；正面留一个 0.7 m 宽的木栅门，门扇半开；
圈内一侧贴墙一个单坡草棚，棚高 1.5 m、进深 1.0 m，草顶；棚下有一个 0.4 m 见方的小鸡舍门洞，木板拼成；
圈内地面为夯土，散少量干草；无动物。
【方位】俯视图里：矩形矮墙围合居中（正面下方留门洞），草棚贴**后墙靠左**一侧、向圈内伸出，鸡舍门洞在棚下贴左后角，门洞朝圈内。
【材质】土坯墙暖灰褐；草顶干黄；木栅门深褐；地面夯土灰褐；干草枯黄。
【负向】无猪、无鸡、无人物、无文字、无瓦顶、无石砌；不要画成整齐的畜舍大棚。
```

出图后看：矮墙围合必须闭合（留门洞），棚顶是草顶；不要出现动物。

### 3.7 农具 + 药篓一组 `village-tools-a`

### 3.10 旧山门残件 `village-old-gate-ruin-a`

```text
【物件定义】中国北方山村旧聚落遗留的一处石山门残件：两根断裂的石柱、两块残石础、一段倒地石匾；只画这组残件，不画完整山门。
【形制】两根石柱：一根残高 2.8 m、柱头断裂；另一根残高 1.6 m、从中间断成两截，上半截倒地；
柱身方形、边长 0.35 m，表面有浅浮雕但已磨蚀（不出现文字）；两块石础 0.6 × 0.6 × 0.3 m，冷灰；
倒地石匾 1.4 × 0.5 × 0.15 m，表面平整但无字；残件周围散碎石与枯草；整体占地约 4.0 × 1.5 m。
【方位】俯视图里写死：高的断柱立在组的**左端**，其石础在柱脚；矮的半截柱立在**右端**，倒地的上半截横躺在右柱**脚边**；
石匾倒地横放在**中前部**，两柱之间；碎石与枯草只散在残件四周。
【材质】石灰岩冷灰、风化、边角磨圆；断口粗糙；石匾表面有雨痕；枯草干黄。
【负向】无完整门楼、无屋顶、无文字、无匾额题字、无人物、无香炉；不要画成完整牌坊。
```

出图后看：断柱与倒地半截必须能对上；石匾上不能出现任何文字或纹样；三张里残件的位置关系一致。

> ★★ **侧视的柱底座是本件最大坑（四版实测）**：模型对"石柱必立在台基上"的先验极强 ——
> v1 画多级线脚台阶、v2/v3 画叠层石板，**怎么写"只有一块方础"都压不住**。
> **最终有效的是量化反制**：「柱身正下方**一块很薄的方石板**（0.6×0.3，只比柱宽出一小圈），
> **底部最宽处不超过柱身宽度的两倍**；绝不是一层比一层宽的金字塔台座；不许纪念碑/牌坊感」—— v4 才收敛。
> ★ 仍残留两柱共用一块长底板（正视是各一块独立础）⇒ **出模以正视为准**，侧视只读柱高、断口与倒匾位置。

## 4. 出图后统一检查

1. **正交**：每张都是单视角正交 —— 正视只见正面；侧视是立面图（另一侧完全藏住，无转角透视）；俯视只见顶面（无任何立面）。
2. **无底座**：所有物件不得带圆形展台、方形底座、地面片。
3. **材质对**：土坯 / 小青瓦 / 旧木 / 冷灰石 / 陶，五类可辨；不要出现红墙金漆、彩画、汉白玉。
4. **无文字**：石匾、门楣、墙面一律无字。
5. **穷村感**：边角磨损、雨痕、缺口、补丁；不要做旧成脏污或焦黑。
6. **单件完整**：物件主体完整入画，不裁切顶部与底部；组类物件不散出画面。
7. ★ **组类三张方位一致**：俯视与正/侧里各件的左右 / 前后关系对得上（按 §3 的【方位】句核）。
8. ★ **俯视量长宽比**：bbox 宽:高 ≈ §0 的「总宽 : 总深」；绝对比例不作硬判据（模型有画胖/画扁偏差，pilot-06 实测 −26%~+59%），朝目标方向、是真平面即可。
